Maps

Мобильное приложение карт на Flutter: живая геолокация, умный поиск рядом, маршруты А → Б, пять слоёв карты и карточки заведений. Проект завершён, дальше он будет только обновляться.

Скриншоты

Возможности

GPS в реальном времени

  • Непрерывное отслеживание позиции с высокой точностью
  • Анимированный маркер: пульсирующий ореол и конус направления
  • Режим автоследования, который мягко отключается при ручном сдвиге карты

Глубокий зум

  • Приближение до 21–22 уровня вплоть до номеров домов
  • За пределами нативного зума сервера тайлы масштабируются без пустых квадратов и ошибок 404

Геопоиск рядом

  • Запросы привязаны к текущей позиции, результаты сортируются по удалённости
  • Бейдж с расстоянием у каждого места (180 м, 1,2 км)
  • Быстрые категории: кафе, магазины, аптеки, АЗС, рестораны

Выбор точки на карте

  • Старт и финиш можно задать прямо на карте
  • Прицел по центру экрана с тактильной отдачей
  • Панель подтверждения и быстрая отмена

Маршруты А → Б

  • Автомобильная маршрутизация OSRM: дистанция и время в пути
  • Любые комбинации: GPS, заведение, сохранённая метка, точка на карте
  • Смена направления одной кнопкой, автозум на весь маршрут

Пять слоёв карты

  • Классика (OSM), спутник, городской (CyclOSM), топографический, ночной
  • Оффлайн-кэш тайлов на диске: быстрее загрузка и меньше трафика

Карточки заведений

  • Галерея фото, рейтинг, отзывы, статус работы, телефон и адрес
  • Действия: построить маршрут, скопировать координаты

Фото и отзывы в карточках демонстрационные.

Устойчивые данные

  • Overpass API с пулом зеркал: при ошибке 504 запрос уходит на другой сервер
  • Локальное хранилище сохранённых меток

Интерфейс

  • Тёмный стиль с эффектом матового стекла (BackdropFilter)
  • Учёт Dynamic Island и безопасных зон

Архитектура

Код разделён на модели, сервисы и виджеты, единая тема вынесена в отдельный файл.

lib/
├── app_theme.dart       # дизайн-система
├── main.dart            # точка входа
├── main_screen.dart     # экран карты
├── models/              # место, отзыв, маршрут, метка, стиль тайлов
├── services/            # GPS, Overpass, OSRM, Photon, хранилище меток
└── widgets/             # шторки, поиск, маркеры, карточки

Тесты

Юнит-тесты покрывают модели и сервисы: расстояние и время маршрута, произвольные точки А → Б, сохранение меток, стили карт, модели заведений и карточки мест.

Запуск

git clone https://github.com/helltrilla/maps.git
cd maps
flutter pub get
flutter analyze
flutter test
flutter run

Нужен Flutter SDK 3.24 или новее и Xcode для iOS.
