TodoApp

Персональный executive-центр на Flutter: утренний AI Daily Digest на базе Google Gemini 2.0 Flash, интерактивная Матрица Эйзенхауэра 2x2 с тактильным Drag-and-Drop, голосовые шорткаты Siri и Google Assistant, 120-дневный Heatmap активности, процедурная DSP аудио-студия концентрации и отказоустойчивая Offline-First синхронизация с Supabase.

Скриншоты

Возможности

🤖 AI Daily Digest (Google Gemini 2.0 Flash)

  • Умная утренняя саммари-сводка на день с анализом дедлайнов и приоритетов
  • Автоопределение главной Top-1 задачи и оптимального окна пиковой энергии (10:00 – 12:30)
  • Кэширование на 24 часа в SharedPreferences и детерминированный оффлайн-движок HeuristicDigestGenerator
  • Неоморфная карточка со skeleton-shimmer анимацией загрузки

🗂️ Матрица Эйзенхауэра 2x2 с Drag-and-Drop

  • Мгновенное переключение между классическим списком и 4 квадрантами (Do, Schedule, Delegate, Eliminate)
  • Тактильное перетаскивание задач через LongPressDraggable и DragTarget
  • Автоматическая реклассификация срочности, важности и приоритетов (P1–P4) при дропе
  • Фирменный Taptic Engine виброотклик при захвате карточки

🎙️ Голосовые шорткаты и Siri Deep Links

  • Интеграция с Siri и Google Assistant через URL-схему todo://
  • Шорткаты рабочего стола iOS (UIApplicationShortcutItems) и Android (shortcuts.xml)
  • Распознавание речи с мгновенным извлечением даты («завтра в 18:00») и приоритета («срочно»)

📊 Дашборд продуктивности & 120-Day Heatmap

  • 120-дневная матрица завершённых задач в стиле GitHub с 4 уровнями активности
  • Круговая диаграмма (Donut Chart) по категориям и уровням приоритета
  • Стрик-трекер непрерывной серии продуктивных дней и аналитика минут фокуса

🎧 Фокус-студия и процедурный DSP-микшер

  • 6 процедурных генераторов звуков (дождь, костёр, белый шум, океан, уютное кафе, винил)
  • Двухканальный микшер громкости: независимая регулировка шумов и музыки
  • Музыкальный хаб (Spotify, Apple Music, Yandex) с поддержкой Lock Screen Now Playing
  • Кастомный Pomodoro-таймер с настройкой от 1 до 120 минут

☁️ Двухсторонняя Offline-First синхронизация

  • Мгновенный локальный отклик интерфейса с нулевой задержкой
  • Фоновая синхронизация с Supabase PostgREST (с поддержкой Pull-to-Refresh)
  • Разрешение конфликтов Last-Write-Wins (LWW) по миллисекундным таймстемпам и RLS-политики PostgreSQL

📱 Интерактивные виджеты iOS 17 (WidgetKit)

  • Нативные виджеты для домашнего экрана и экрана блокировки на Swift / SwiftUI
  • Синхронизация через Apple App Groups без открытия основного приложения
  • Интерактивные кнопки: отметка выполнения задач и запуск таймера

💾 Экспорт через Dart Isolates

  • Фоновая сериализация без просадок 60 FPS интерфейса
  • 3 формата экспорта: JSON (полный бэкап), RFC 4180 CSV (Excel/Sheets) и Markdown (Obsidian)
  • Нативный системный Share Sheet (AirDrop, Telegram, Files)

🎨 4 темы, цветовая палитра и 5 языков

  • Dark, обновлённая высококонтрастная Light, System и ультрачёрный AMOLED Midnight (#000000)
  • Селектор акцентных палитр оформления
  • Мгновенная локализация без перезапуска (RU, EN, DE, FR, SR) с учётом правил плюрализации

Архитектура и Тесты

Кодовая база структурирована строго по Feature-First Clean Architecture с изоляцией domain-сущностей, use case, репозиториев и UI.

101/101 тестов успешно проходят (100% green) — автоматизированные unit- и widget-тесты покрывают AI Digest, Матрицу Эйзенхауэра, отказоустойчивый синк, парсинг диплинков и сценарии авторизации.

lib/
├── core/                # Темизация, локализация, Haptics, Deep Link Router
├── features/
│   ├── ai_digest/       # Gemini 2.0 Flash REST API + Heuristic Fallback
│   ├── matrix/          # 2x2 Eisenhower Drag-and-Drop Grid
│   ├── tasks/           # Clean Architecture: domain, data, presentation
│   ├── focus/           # Procedural DSP Audio Engine & Pomodoro Timer
│   └── auth/            # Supabase OTP REST API + Local Auth
└── main.dart            # MultiProvider, делегаты локализации, точка входа

Запуск

# 1. Клонирование репозитория
git clone https://github.com/helltrilla/todo.git
cd todo

# 2. Установка зависимостей
flutter pub get

# 3. Запуск анализатора кода и 101 теста
flutter analyze --fatal-infos
flutter test

# 4. Запуск на симуляторе или устройстве
flutter run

# 5. Запуск веб-версии (PWA)
flutter run -d chrome

Требуется Flutter SDK 3.10+ и Xcode для запуска на iOS.
