TodoApp

Современный менеджер задач на Flutter: настраиваемые категории с иконками, подзадачи с прогрессом, встроенный Pomodoro-таймер фокусировки и надёжная авторизация через Supabase OTP.

Скриншоты

Возможности

Умные задачи и подзадачи

  • Создание подзадач внутри любой задачи с интерактивными чекбоксами на карточке
  • Бейдж прогресса (напр. 2/3)
  • Автоматическое завершение задачи при выполнении всех подзадач

Кастомные категории

  • Конструктор категорий с выбором из 12 тематических иконок и 10 цветовых палитр
  • Глобальная категория «Общее» с золотой подсветкой для общих задач

Двухрежимная авторизация

  • Вход по Email с настоящим 6-значным кодом (через Supabase Auth REST API)
  • Внутренний профиль (логин/пароль) с локальным хранением для офлайн-работы

Интерактивный онбординг

  • Приветственные слайды с векторной графикой при первом запуске
  • Запоминание статуса первого входа

4 уровня приоритета

  • P1 — Срочно 🔥 (красный акцент и выделенная рамка карточки)
  • P2 — Высокий ⚡ (оранжевый акцент)
  • P3 — Средний 📌 (фиолетовый акцент)
  • P4 — Низкий 🌿 (зелёный акцент)

Таймер фокусировки

  • Встроенный Pomodoro-таймер для концентрации над задачами

Архитектура

Приложение построено по принципам Feature-First Clean Architecture, разделяя логику, данные и UI.

Стек

  • Flutter
  • Dart
  • Provider
  • go_router
  • Supabase
  • Google Fonts
  • shared_preferences

Запуск

git clone https://github.com/helltrilla/todo.git
cd todo
flutter pub get
flutter analyze
flutter test
flutter run

Необходим Flutter SDK 3.10 или новее.
