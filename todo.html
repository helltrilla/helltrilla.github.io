TodoApp

Многофункциональный менеджер задач: PWA, виджеты iOS 17 (WidgetKit), распознавание речи с NLP и Gemini AI, тепловая карта продуктивности и двухсторонняя оффлайн-синхронизация через Supabase.

Скриншоты

Возможности

Дашборд продуктивности

  • 120-дневная Heatmap-матрица (как в GitHub) с 4 уровнями активности
  • Круговая диаграмма (Donut Chart) приоритетов и категорий
  • Стрик-трекер: отслеживание серии дней без пропусков (Streak)

Интерактивные виджеты iOS 17

  • Нативные виджеты на Swift/SwiftUI (WidgetKit + App Groups)
  • Выполнение задач и запуск таймера прямо с Home/Lock Screen

Речь в текст + AI и NLP

  • Движок NLP парсит сроки («завтра в 18:00») и приоритеты («срочно»)
  • Gemini Flash API для сложных ИИ-запросов и анализа намерений

Двухсторонняя Offline-First синхронизация

  • Локальная работа с нулевой задержкой
  • Синхронизация с Supabase PostgREST в фоне (с поддержкой Pull-to-Refresh)
  • Резолв конфликтов (LWW) по времени изменения (updatedAt)

Экспорт данных через Isolates

  • Тяжелая сериализация данных вынесена в фоновые изоляты (Dart Isolates)
  • Экспорт в форматы JSON, CSV (для Excel/Google Sheets) и Markdown

Фокус-студия и аудиоплеер

  • Генератор фонового шума (дождь, океан, кафе) с микшером громкости
  • Интеграция с экраном блокировки iOS (Control Center Now Playing)
  • Pomodoro-таймер с настройкой от 1 до 120 минут

Кроссплатформенность и темы

  • Сборка под Web (PWA) и мобильные устройства
  • 4 темы оформления, включая глубокий AMOLED Midnight (#000000)
  • Мгновенная локализация на 5 языков (RU, EN, DE, FR, SR)

Архитектура

Проект построен по подходу Feature-First Clean Architecture. Реализована строгая изоляция слоёв, RLS-политики на стороне базы данных Supabase и эффективная работа с кэшем.

Запуск

git clone https://github.com/helltrilla/todo.git
cd todo
flutter pub get
# Запуск на устройстве:
flutter run
# Запуск в браузере (Web PWA):
flutter run -d chrome

Необходим Flutter SDK 3.10 или новее.
